# 7. 24H VOLUME — ВОСПРОИЗВЕСТИ ИМЕННО PINE

Очень важно.

Не заменять формулу Pine готовым Bybit `turnover24h`.

Исходный Pine рассчитывает fixed-time 24h volume через 24 часовых свечи.

Воспроизвести именно эту модель.

Для режима, эквивалентного `syminfo.volumetype == base`:

`quote_notional = volume * HLC3`

где:

`HLC3 = (high + low + close) / 3`

и затем:

`sum(last 24 hourly quote_notional)`.

Для quote-volume feed использовать volume напрямую.

USD-like quotes:

* USD;
* USDT;
* USDC;
* FDUSD;
* TUSD;
* BUSD;
* USDE

могут использовать 1:1 fallback так же, как Pine.

Хранить отдельно:

* native Bybit turnover;
* Pine-compatible volume24hProxy.

Но baseline calculations должны использовать именно Pine-compatible value.

# 10. TRADINGVIEW REALTIME EXECUTION MODEL

Это критически важная часть.

Pine indicator на открытой realtime candle выполняется многократно.

Перед новым realtime execution обычные series/`var` значения Pine откатываются к последнему confirmed state.

`varip` значения при этом сохраняются внутри открытого бара.

Python engine должен воспроизвести эту семантику.

Реализуй модель примерно такого уровня:

`ConfirmedState`
+
`RealtimeWorkingState`
+
`IntrabarPersistentState`

При каждом новом realtime market update:

1. взять committed state предыдущего закрытого chart bar;
2. восстановить обычный Pine state;
3. применить текущее состояние открытой candle;
4. пересчитать Pine logic;
5. сохранить только эквиваленты `varip`;
6. отправить current snapshot/UI update;
7. не commit обычного state до закрытия candle.

При closing tick:

* выполнить последний calculation;
* commit state;
* перевести candle в confirmed;
* открыть следующий realtime state.

Это необходимо для точного воспроизведения:

* `avgSetupIntrabarSum`;
* `avgSetupIntrabarSamples`;
* `AVG SETUP`;
* `avgSetup70CrossThisBar`;
* `execution65CrossThisBar`;
* realtime threshold alerts.

Не реализовывать realtime как простой cumulative mutation одного Python object — это даст отличия от TradingView rollback.

# 40. PARITY ACCEPTANCE CRITERIA

Для CLOSED BARS target:

### Price-based values

* OHLC: exact exchange tick;
* structural levels: <= 1 tick deviation;
* SL/T1: <= 1–2 ticks там, где formula deterministic.

### Indicators

ATR/EMA:

* relative error target <= 0.05%.

### Scores

Formation / Execution / Geometry / Context / MAE / Exhaustion / Level / AVG SETUP:

* median absolute error <= 0.5 percentage point;
* P95 <= 1.5 percentage points.

### Discrete state

* Direction: exact;
* FSM: exact;
* Candidate Path: exact;
* Trigger Path: exact;
* ACTION: exact;
* WATCH/ENTRY/BRONZE/STRONG signal candle: exact.

Target state agreement:

`>= 99%` на валидном reference dataset.

Если parity хуже — не маскировать допусками.

Найти корневую причину.
